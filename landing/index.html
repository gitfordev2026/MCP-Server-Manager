How It Works

From REST API to MCP Tool in Minutes

Six steps. Fully automated. Zero code changes to your existing APIs.

01

Register

Point MCP Manager to any OpenAPI specification URL. Supports JSON and YAML.

02

Discover

Automatically crawl and detect every endpoint, method, parameter, and schema.

03

Generate

Convert each endpoint into a typed MCP tool with JSON Schema input validation.

04

Secure

Apply Keycloak JWT verification, RBAC roles, and per-tool access policies.

05

Publish

All tools merge into one unified, authenticated MCP endpoint at /mcp/.

06

Connect

Claude, Cursor, VS Code, and custom agents discover and call authorized tools.

Security

Enterprise-Grade Authentication Built In

Every tool call is authenticated, authorized, and audited. No exceptions.

JWT Verification

Cryptographic token validation via JWKS. Every request verified against Keycloak's public keys in real time.

RBAC Enforcement

Role-based access control with Keycloak realm and client roles. Permissions enforced at every API layer.

Per-Tool Policies

Allow, deny, or require approval per tool. Three-tier inheritance from system → owner → tool level.

Token Forwarding

JWT tokens forwarded to downstream APIs so your services can independently verify the calling user's identity.

Scope Validation

Audience, issuer, and scope claims validated. Expired or malformed tokens rejected instantly.

Audit Trail

Immutable log of every action with before/after state snapshots. Full forensic traceability.
